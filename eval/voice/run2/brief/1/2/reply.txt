It all starts from one token file. That single file builds the site's styles, the Figma library, and the rules Claude reads, so everything stays in sync. The rules live in a design document that both people and Claude follow. There are two typefaces, twelve type sizes, a four pixel spacing base, nine base colors, and a Day and a Dusk theme. Seven automated checks run on every build, covering things like color contrast, using only tokens, and reduced motion. You can see it all live on the system page of this site.
