It all starts from one token file. That single file builds the site's styles, the Figma library, and the rules that Claude reads, so everything stays in sync. The rules themselves live in a file called design dot M D, written for both people and Claude. The system has two typefaces, twelve type sizes, a four pixel spacing base, nine base colors, and a Day and a Dusk theme. A set of checks runs on every build. They cover things like text contrast, using tokens only, and reduced motion. If you'd like to see it live, the system page on this site shows all of it. I can also tell you about the test she ran on it with Claude.
