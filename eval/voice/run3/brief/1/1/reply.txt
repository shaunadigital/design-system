It all starts from one token file. That single file builds the site's styles, the Figma library, and the rules that Claude reads, so everything stays in sync. Those rules also live in a design document at the root of the repo, written for both people and Claude. The system is small on purpose: two typefaces, twelve type sizes, a four pixel spacing base, and nine base colors, with a Day and a Dusk theme. Seven automatic checks run on every build, covering things like color contrast and using tokens only. If you'd like to see it live, there's a specimen page at the system page on this site.
