It all starts from one token file. That single file builds the site's styles, her Figma library, and the rules that Claude reads, so everything stays in sync. The rules themselves live in a file called DESIGN dot M D, written for both people and Claude.

The system is small on purpose: two typefaces, twelve type sizes, a four pixel spacing base, and nine base colors, with a Day and a Dusk theme.

Seven automatic checks run on every build. They cover things like text contrast, using only tokens, and reduced motion.

If you'd like to see it live, the system page on her site shows every piece. I can also tell you about the test she ran of this system on Claude.
