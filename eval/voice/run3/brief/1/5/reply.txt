It all starts from one token file. That single file builds the site's styles, the Figma library, and the rules that Claude reads, so everything stays in sync. The rules themselves live in a design file at the root of the project, written for both people and Claude. The system has two typefaces, twelve type sizes, a four pixel spacing base, nine base colors, and a Day and Dusk theme. Seven automatic checks run on every build, covering things like color contrast, tokens only, and reduced motion. If you'd like to see it live, the system page on the site has a full specimen.
