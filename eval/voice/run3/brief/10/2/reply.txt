A standard DESIGN.md is a page of written rules. Her system adds one token file behind those rules. That file builds the styles, the Figma library, and the rules Claude reads, so they all agree.

She tested it in a second round with two hundred forty page builds on Claude. Both groups nearly always passed. The standard file passed one hundred eighteen of one hundred twenty pages. Her system passed all one hundred twenty.

The real gap was consistency. The standard file produced thirty button styles and sixteen field styles. Her system produced seven button styles and four field styles.

The full write-up is in the case study on testing a design system on Claude.
