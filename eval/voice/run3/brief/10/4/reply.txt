A standard DESIGN.md is a set of written rules that Claude reads. Shauna's system adds one token file behind those rules. That single file builds the site's styles, the Figma library, and the rules Claude reads, so everything comes from the same source.

She tested the difference in a round of two hundred forty page builds. Both groups almost always passed the checks. The standard file passed one hundred eighteen of one hundred twenty pages, and her system passed all one hundred twenty. The bigger gap was consistency. The standard file produced thirty different button styles and sixteen field styles. Her system produced seven button styles and four field styles.

The full write-up is in the case study on testing a design system on Claude.
