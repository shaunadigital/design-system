It all starts from one file of design tokens. That single file builds the site's styles, the Figma library, and the written rules that Claude reads, so everything stays in sync. The system has two typefaces, twelve type sizes, a four pixel spacing base, and nine base colours, with a day theme and a dusk theme. On every build, seven automatic checks run. They cover things like text contrast, using only token values, and accessible labels. If you'd like to see it live, the system page on this site has a full specimen.
