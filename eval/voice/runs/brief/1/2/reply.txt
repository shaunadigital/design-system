It all starts from one token file. That single file builds the site's styles, the Figma library, and the rules Claude reads, so everything stays in sync. The rules themselves live in a document called design dot M D, written for both people and Claude. The system uses two typefaces, twelve type sizes, a four pixel spacing base, and nine base colours, with a day theme and a dusk theme. Every build runs seven automatic checks, covering things like text contrast and using tokens only. If you'd like to see it live, the system page on this site shows every piece.
