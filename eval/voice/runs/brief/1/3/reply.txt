It all starts with one token file. That single file builds the site's CSS, her Figma library, and the rules that Claude reads, so everything stays in sync. The system has two typefaces, twelve type sizes, a four pixel spacing base, nine base colours, and Day and Dusk themes. A written rulebook covers both people and Claude. And a set of seven checks runs on every build, covering things like text contrast, tokens only, and reduced motion. In her test on Claude, her system passed every page and produced far fewer button and field styles. You can see it live on the system page of this site.
