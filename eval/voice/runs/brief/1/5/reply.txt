It all starts from one token file. That single file builds the site's styles, the Figma library, and the rules that Claude reads, so everything stays in sync. The rules themselves live in a file called design dot M D, written for both people and Claude. The system is small on purpose: two typefaces, twelve type sizes, a four pixel spacing base, nine base colours, and a day and a dusk theme. Seven automatic checks run on every build, covering things like text contrast and using tokens only. If you'd like to see it live, the system page on this site has the full specimen.
