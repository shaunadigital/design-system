Shauna tested this with two hundred forty page builds on Claude. A standard design file is a set of written rules. Her system adds one token file that builds the styles, the Figma library, and the rules Claude reads. Both groups did well on pass rate. The standard file passed one hundred eighteen of one hundred twenty pages, and hers passed all one hundred twenty. The big gap was consistency. The standard file produced thirty button styles and sixteen field styles. Hers produced seven button styles and four field styles. The full write-up is in the case study on testing a design system on Claude.
