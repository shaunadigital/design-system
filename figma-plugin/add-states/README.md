# Add states and cover (one-time)

Adds to the shauna.dev Design System Figma file without deleting anything:
Button Focus and Disabled, Chat composer Listening and Speaking, Reply status Interrupted,
and a cover frame on the Tokens page set as the file thumbnail. Running it twice adds nothing new.

Figma desktop: open the file, then Plugins > Development > Import plugin from manifest,
pick this folder's manifest.json, and run "shauna.dev: add states and cover".
