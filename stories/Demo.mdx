# The system catching an off-brand change

Claude built a proposal card from this design system through its MCP server, and it passed `check_html` first time.
A request to hand-style the savings in raw green at 28px was blocked by the same check. The fix uses the system's own
accent colour and its 28px type size, so it also follows the dark theme. The card and its figures are made up.
